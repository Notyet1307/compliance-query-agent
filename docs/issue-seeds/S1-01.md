# 固定真实等保资料与人工参考答案

Seed-ID: SEED-S1-01

Status: CANDIDATE — 用户已确认拆分与依赖，未发布、未批准实施。

Parent: SEED-S1；依据 [已审阅规格](../specs/s1.md)。

## User outcome

安全售前／咨询人员可通过现有 query CLI 对一个明确日期的全国定级／备案问题取得已审核原文与定位，并由人工核对参考答案；来源不足则明确待复核，不冒充真实 LLM 回答。

## What to build

从 [来源候选与访问限制](../research/s1-source-candidates.md) 出发，通过可信正式渠道取得并核对原文、版本、适用条件、现行状态、许可与外发／公开保存范围。与用户固定问题、查询日期、参考点和禁止说法；专业判断不足处由指定审核者补审，助手不能代签。

仅将获审核来源形成管理员管理的本地快照。复用资料资格过滤及关键词检索，补充真实样例必要的元数据和检索能力，不扩大到向量平台。建立原 S1 正常、无依据、时效不明、版本边界、恶意正文样例清单；受控变体与真实资料分离。通过原文提取 CLI 和已有业务测试证明资料选择／拒绝行为，作为后续真实模型验收的输入，而非替代它。

## Acceptance criteria

- [ ] 固定至少一个真实问题、查询日期、原文／定位／版本／摘要、来源权限记录及用户认可的参考答案；不可认证取得或效力／许可未审核时标 BLOCKED，不伪填核验日期。
- [ ] 正常资料经 CLI 返回可核对原文，标 `REFERENCE_ONLY`；不能标成 S1-A01 的真实模型 PASS。
- [ ] 无依据、时效不明、历史有效区间终点与重叠冲突有可执行验证，分别得到批准的不足／待复核／版本选择结果，无新增模型调用。
- [ ] 新建与已运营的起算点、材料主体与级别条件不被合并；地方材料及承诺时限不作为全国要求。对争议原文保留审核记录，不自行裁决现行效力。
- [ ] 五类样例的输入、预期引用、可接受说明、禁止说法及对抗数据性质明确；未获准对外发送的变体不得列入真实模型执行清单。
- [ ] 资料快照／输入／预期／代码候选有摘要；修改代码时运行目标工具链 `make verify` 及本切片 CLI 场景，说明环境与实际结果。文档或资料验证不冒充真实集成。

## Blocked by

无其他 S1 子工单依赖。开始实施仍需独立授权；完成依赖正式原文取得、来源许可／效力审核及人工参考答案确认。当前候选访问／效力缺口见来源记录，不能把“无工单依赖”当就绪授权。

## AC mapping

S1-A02／A03／A04／A06 的资料与检索侧，A01／A05 的批准样例前提及 A10 的快照证据。真实模型部分由 SEED-S1-03 验收。

## Out of scope

真实模型调用、客户材料、用户上传 API、RAG／向量平台、OctoBus 或 agent-compose 运行、来源自动审批、标准全文再分发、改写 S1 AC。

## Evidence and handoff

交付来源审核记录、固定 corpus 与样例清单、人工参考答案、实际 CLI 命令及输出摘要、异常验证结果、代码／配置／资料摘要。只公开允许公开的内容，未满足前提逐项 BLOCKED。禁止自动发布 Issue、commit／push 或追加运行。
