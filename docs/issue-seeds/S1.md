Status: CANDIDATE — 未发布、未批准执行。

Parent: CQA 首个可受管使用的安全合规查询智能体里程碑（正式父 Issue 未建立）。

## User outcome

用户输入一个真实等保查询，得到可人工核验的资料回答或明确依据不足。

## What to build

确定授权资料与人工标准答案；保持其他四域的范围声明；增加必要来源/版本/适用条件元数据；使用选定模型生成有引用草稿；改善检索仅以真实样例需求为依据。

## Acceptance criteria

至少一个真实正常样例和无依据、时效不明、版本边界、恶意正文异常链路；原文/定位/版本能人工核对；引用 ID 校验不冒充语义证明；所有外发数据/费用在授权范围；证据绑定代码/资料快照。

SEED-X1

## Out of scope

自动合规通过判断、大规模全文抓取、复杂向量平台、无授权标准再分发。

## Evidence

固定实际代码 SHA/差异、批准 Spec、输入/预期/实际输出和环境。记录真实命令及日志，mock 和 live 分开。不得提交秘密/客户原文，缺环境标 BLOCKED，未执行标 NOT_RUN。
