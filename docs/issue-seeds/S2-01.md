## What to build

操作者使用固定 query CLI，在真实 agent-compose guest 中经原生能力通道调用 OctoBus 的固定只读 Search，取得与 S1 相同的合成测试文档及结构化原文结果。daemon 只持查询凭据，管理凭据只用于操作者预置。错误权限、无依据和服务失败可被区分，不让查询链路为了平台目录注入而静默获得管理权限。

复用已有原生客户端、真实 SDK／protobuf 服务包和来源筛选，将服务包供给的数据固定为规格中的单文档，不新增知识库、上传、RAG 或通用 adapter。该服务不是 OctoBus 内置知识库；现有 X1 示例数据不能不经替换和摘要核对就冒充 S1 测试文档。保留 X1 的历史包／运行证据，不通过覆盖旧证据改变结论。

本票保持原文提取，正常结果为 `REFERENCE_ONLY`、模型未调用；它是独立可验证的数据面切片，**不是 S2-A01 的模型草稿通过，也不证明跨重建重放**。不提前放宽旧 X1 的 LLM 限制。下一票在此已证实的查询通路上完成模型与恢复闭环。

## Acceptance criteria

- [ ] **S2-01-AC1 — 固定真实候选。** 记录本仓库组合候选、未发布 X1 改动、目标 Go、agent-compose／OctoBus 版本、镜像 digest 与 guest 架构；输入／资料／服务包／配置和预期有摘要。S1 的已发布 SHA 不替代混合构建；运行前确认专用私有回执位置及实际挂载，不绕过存储或把临时目录称为恢复保证。
- [ ] **S2-01-AC2 — 最小权限正常通路。** S2-G2 通过：仅查询凭据在开启真实认证时可完成固定 Search，并记录平台目录流程的实际处理；正常问题经真实 guest 返回 `REFERENCE_ONLY`、`synthetic_demo`、正确引用／原文摘要、`humanReviewRequired:true`、`entailmentVerified:false` 和 `tokenUsage.status=not_called`。证明 Search 到达实际业务处理器，模型调用为零；目录告警、平台启动或 JSON echo 都不是替代证据。
- [ ] **S2-01-AC3 — 权限拒绝。** 完成 S2-A05：错误／未授予 capset、无效能力凭据被拒绝，不返回成功业务结果；分别记录网关拒绝和知识服务是否到达。验证 guest 无管理能力及非批准访问路径；排除残留管理 token、关闭认证或扩大 capset 的假通过。不兼容即停止并报 BLOCKED，不升权、不沿用 X1 管理级测试凭据、不回退 Direct。
- [ ] **S2-01-AC4 — 无依据与来源异常。** 同文档无依据问题返回 `INSUFFICIENT_EVIDENCE`、空 claims／citations；受控未核验、过期核验、重叠版本按既有规则待复核，摘要篡改拒绝，真实资料模式仍拒绝 synthetic。此处是 S2-A02／S2-A03 的数据面证据；模型启用后的零发送保证仍由下一票验证，不能仅因 extractive 不发模型而声称已证明生成闸门。
- [ ] **S2-01-AC5 — 失败不伪造成功。** 原生服务不可达／取消保留固定安全错误和未知运行引用；预留、blocked 回执不删除，同 ID 再提交不新增 Search。无依据与鉴权／传输失败不混记；超时不冒称远端停止。交付 S2-A11 的 Search 部分，不把后续模型错误延期为本票未说明的缺口。
- [ ] **S2-01-AC6 — 输入与凭据边界。** 受控问题／正文只能经 JSON 文件进入固定命令；不能更改方法、capset、端点或执行 shell。guest 不持上游或管理凭据，不挂 HOME／宿主根／Docker socket；检查批准的挂载、网络与拒绝路径，扫描本轮产物中的精确测试秘密。交付 S2-A13 的数据通路证据，不声称生产隔离或通用 DLP。
- [ ] **S2-01-AC7 — 本票独立交付。** 在目标工具链执行 `make verify`，并运行真实 CLI 的必要正常／异常检查；软件模拟与真实 gRPC／OctoBus 分列。交付命令、退出状态、输入／配置／资料／候选摘要、平台引用、Search 计数与每项结论；G2 或本票必需真实场景未运行时不能称本票完成。按授权清单停止本次资源，保留回执和证据，不把验证推至下一票或 R0。

## Blocked by

- 未完成的前置 S2 候选：无。已接受 S1 单文档与 X1 原生试验是可复用证据，不把整个 S1 原真实法规范围当成本票前置条件，也不将已关闭工单状态当作充分交付证明。
- **执行闸门，非工单依赖：** 本票粒度及依赖已获认可，本轮仅开展离线实施／验证；必要的镜像／环境操作、固定运行包及测试凭据预置仍须授权。旧授权不续期，本票不请求或使用真实模型密钥。
- 最小权限与平台目录兼容性是本票要解决的关口，不另造一张无交付的“等待兼容性”前置票；失败须记录具体原因并返回用户决策。

## Out of scope

受管 LLM、百智云真实调用、G1／G3 通过、跨 guest 恢复保证、生产知识服务、真实法规资格审核、上传／RAG、Accord、查询链路管理权限、自动升权／重试／Direct 回退、通用控制器；未经授权安装／启动资源、发布 Issue 或 commit／push／merge／release。
