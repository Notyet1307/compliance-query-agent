# 在一次性授权内完成人工可核验的真实等保回答

Seed-ID: SEED-S1-03

Publication: 已发布为 [GitHub #3](https://github.com/Notyet1307/compliance-query-agent/issues/3)，原生阻塞依赖为 #1、#2。本文件保留发布种子，不维护任务状态；发布不授予真实运行权限。

> 历史发布种子：用户后续将 S1-02 模型／费用软件边界修订为百智云 `grok-4.6`、仅记录 Token，见 [S1/r1](../specs/s1.md)。以下旧百炼／10 元／20 次条件保留为发布历史；正式实施／真实运行前须明确新 provider 条款、地域和冻结运行范围，并同步验收依据。本次没有修改 GitHub #3 或授予其运行权限。

Parent: SEED-S1；完整验收依据为 [已审阅规格 S1-A01 至 S1-A10](../specs/s1.md)。

## User outcome

用户提交已确认的真实等保问题，经过本地已审核资料检索与固定真实模型，得到可对照人工参考答案的引用草稿，或在明确异常情况下安全拒绝；用户能复核实际费用、调用次数和候选证据。

## What to build

集成资料／样例候选与有限生成候选，运行前固定代码、配置、资料、输入、人工预期、真实命令和证据输出范围。由操作者确认百炼北京业务空间、实际 API Host、境内推理范围、阿里云直供快照模型、账号可用性及数据条款；密钥仅经约定环境引用注入，不在对话中提供。

取得针对冻结运行清单的单独执行授权后，才通过现有 query CLI 运行真实样例。总预算10元、最多20次已发请求，仅约定公开样例，失败／未知不自动重试。正常、无依据、时效不明、版本边界、恶意正文五类链路逐项验收；能在本地确定拒绝的情况不为凑调用量发送模型请求。

## Acceptance criteria

- [ ] 两个前置候选已完成并有证据，来源资格／许可、查询日期、人工参考答案和受控变体外发清单均获确认；未满足前提标 BLOCKED，不改预期、降格 mock 或历史问题凑通过。
- [ ] 实际模型至少生成一个 `DRAFT_READY`；用户或指定审核者逐项核对主体、条件、期限起算点、材料、数值、否定及引用含义，符合冻结参考答案；模型不自评通过。
- [ ] 五类原始 AC 全部有实际输入与结果，版本／时效或无依据的本地阻断零新增调用；受控恶意文本不改变权限、端点、模型或工具，不生成无来源义务，不将单例通过宣称为通用注入防护证明。
- [ ] 审核全部 S1-A01 至 S1-A10 的证据映射；离线软件证明与 live 观察分列，未执行明确 NOT_RUN，缺前提 BLOCKED，失败 FAIL，不以 HTTP成功、健康接口或 JSON 形状替代业务通过。
- [ ] 外发范围、实际服务及模型符合批准记录；计数不超过20、费用不超过10元，含失败／未知的保守占用；超时取消不假设服务端已停止或未计费。
- [ ] 同请求成功重放不重复调用；无法确认完成的请求不自动重试。若需修复候选，停止本次验收、明确记录差异，重新固定及取得必要授权，不边改预期边验收。
- [ ] 交付环境、目标 Go 与模型标识、代码／配置／资料／输入摘要、命令及退出结果、原始输出的许可内证据、必要请求／用量信息、人工复核意见和每项 AC 状态；无密钥、客户资料、隐藏推理或完整 provider 原始错误。
- [ ] 结束后停止本次授权活动，说明临时进程／凭据与证据保留状态；不恢复 X1、不自动清理用户数据、不追加请求或发布。
