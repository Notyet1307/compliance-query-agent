## 与当前客户端的差距

核对 `internal/agent/clients.go` 的 `llmGenerator.Generate`：当前发送非流式 JSON Object 请求，但仅有 `max_tokens`，未发送 `enable_thinking` 或 `max_completion_tokens`。

官方 Chat API 参数说明指出 `max_tokens` 即将废弃，通常不包含思维链；`max_completion_tokens` 包含完整输出，Qwen3.5-Plus 及之后版本支持，实际值最多可能存在 10 Token 误差。因而不能把当前 `maxTokens` 配置直接称为本候选的完整计费输出上限。未来获批实施时须明确关闭思考并正确限制完整输出，验证参数兼容与真实响应；本轮不改源码，不声称即插即用。
